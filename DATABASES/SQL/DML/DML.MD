# DML - Data Manipulation Language (Linguagem de Manipulação dos Dados)

Os comandos DML são usados para manipular os dados armazenados nas tabelas de um banco de dados.

## Lista de Comandos DML

| Comando | Descrição | Exemplos |
|---|---|---|
| SELECT | Permite recuperar dados armazenados | [Exemplos de Uso](./SELECT/) |
| INSERT | Serve para modificar estruturas | |
| UPDATE | Serve para deletar objetos | |
| DELETE | Limpar uma tabela por completo | |

## Lista de Cláusulas:

| Cláusula | Descrição |
| --- | --- |
| WHERE | Compara uma coluna com alguma condição |
| ORDER BY | Ordena os dados baseado em uma coluna com alguma condição |
| GROUP BY | Agrupa os dados baseado em uma condição |
| HAVING | Filtra os dados que possui um valor |
| JOIN | Usado para junção e conexão de dados de diferentes tabelas através dos atributos dela |
